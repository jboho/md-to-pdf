## Notes
- First release published (2026-09-12): `v1.0.1` is live — `MD.to.PDF-1.0.1-arm64.dmg` (135.6 MB) + `latest-mac.yml`, built by run `34724863506` from `40806bc`. Two things had to be fixed to get there. (1) **Signing**: the first tagged run (`34722879090`) failed in electron-builder's own `CSC_LINK` path — it creates a temp keychain with a random password, then runs `security set-key-partition-list -k $CSC_KEY_PASSWORD`, passing the *cert* password where the *keychain* password is required (`SecKeychainUnlock: The user name or passphrase you entered is not correct`). Fix in PR #11: import the cert into a keychain we control, put it first on the user search list, and let electron-builder discover the identity — `CSC_LINK`/`CSC_KEY_PASSWORD` are deliberately *not* passed to `npm run dist`. A "Verify the app is Developer ID signed" step was added as a hard gate, because electron-builder exits 0 with an ad-hoc unsigned build when it finds no identity. (2) **Tag placement**: `v1.0.1` had already been pushed at `4079f94`, one commit *before* the signing fix, and a tag does not re-fire on re-push — it had to be deleted remote-side and recreated at `40806bc`. Safe only because that first run failed and published nothing (0 releases at the time). Note for next time: cut the tag *after* the fix is on main, or burn a patch version instead.
